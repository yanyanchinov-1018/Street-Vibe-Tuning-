# Street Vibe Tuning — лендинг

Статический одностраничник: `index.html` + `styles.css` + `main.js` + `i18n.js`. Без сборки и зависимостей.

## Запуск

```bash
npx serve . -l 4173
```

Открывать через сервер, а не двойным кликом.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка. Весь текст размечен ключами `data-i18n*` |
| `styles.css` | Токены, компоненты, адаптив, режимы `hover:none` и `prefers-reduced-motion` |
| `i18n.js` | Словарь RU / UZ / EN — три параллельных набора плоских ключей |
| `main.js` | Локализация, модальное окно, фильтры, компаратор, мобильное меню |

## Дизайн-система

| Токен | Значение | Роль |
|---|---|---|
| `--void` | `#0A0A0B` | матовый чёрный фон |
| `--graphite` / `--carbon` | `#131418` / `#1C1E23` | панели, карточки |
| `--edge` | `#2A2D34` | хайрлайны, границы |
| `--gold` | `#C8A24A` | акцент: кнопки, спецификации, цифры |
| `--gold-hot` | `#F0D48A` | блик, свечение гексов |
| `--smoke` | `#9C9DA4` | вторичный текст |
| `--tap` | `44px` | минимальная тач-зона, применена ко всем интерактивным элементам |

Шрифты: **Unbounded** (дисплей, 800–900), **Golos Text** (тело), **JetBrains Mono** (техметки). Все три с полной кириллицей и латиницей.

Сквозной элемент — гексагональная световая сетка (`.hexrig`), зафиксированная за контентом. Базовый слой виден всегда; второй подсвечивается радиальной маской под курсором. На тач-устройствах и при `prefers-reduced-motion` слой отключён.

## Локализация

Ключи плоские: `'svc1.title'`, `'form.name.ph'`. Ключи с суффиксом `.html` содержат разметку.

Атрибуты в разметке:

| Атрибут | Что подставляет |
|---|---|
| `data-i18n` | `textContent` |
| `data-i18n-html` | `innerHTML` (для `<br>`) |
| `data-i18n-ph` | `placeholder` |
| `data-i18n-label` | `aria-label` |

Переключение идёт без перезагрузки: обновляются тексты, `<html lang>`, `<title>`, `meta description`, подписи кнопок и состояния `aria-pressed`. Выбор сохраняется в `localStorage` под ключом `svt.lang`; при первом визите берётся язык браузера, иначе RU.

**Добавить язык:** добавьте набор в `i18n.js`, впишите код в массив `LANGS` в `main.js` и добавьте кнопку в `.lang` в разметке.

**Добавить строку:** добавьте ключ во все три набора и повесьте `data-i18n="ключ"` на элемент.

Заголовок героя подгоняется по ширине контейнера скриптом `fitHero()` — слова разной длины («Искусство» / «Benuqsonlik» / «The art of») встают флешем в каждом языке, без ручных клампов.

## Куда подставить свои материалы

**Логотип.** Инлайн-SVG в `index.html` (`.brand__mark`). Замените пути на контуры настоящего лого — градиент `#au` подхватится.

**Видео в герое.** Укажите путь в константе `HERO_VIDEO` в `main.js` (сейчас `null`). Формат: 1920×1080, ≤ 8 МБ, без звука, зацикленный. На тач-устройствах видео не грузится намеренно — трафик и батарея важнее эффекта.

**Фото услуг.** `.card__plate--detail / --ceramic / --exhaust` в `styles.css`: замените `background` в `::before` на `url("assets/…")` + `background-size:cover`.

**Галерея.** Классы `.shot__img--g1`, `--p1` и т. д. Для карточек «до/после» нужны две плашки: `--g1` (до) и `--g1after` (после).

**Аватары отзывов.** `.rev__ava--1…4` — градиенты меняются на `url(...)`, шестиугольная обрезка уже задана.

**Контакты.** Телефон, адрес и Instagram — в блоке `#booking` и в ключе `fail` в `i18n.js`.

## Связь с клиентом

Формы на сайте нет — все CTA ведут напрямую в мессенджеры, в новой вкладке (`target="_blank" rel="noopener"`).

| Точка | Куда ведёт |
|---|---|
| Кнопка `Запись` в хедере | Telegram |
| CTA в герое | Telegram |
| `Обсудить в Telegram` на карточках услуг (×3) | Telegram |
| CTA в мобильном меню | Telegram |
| Карточка канала Telegram | Telegram |
| Карточка канала Instagram | Instagram |

**Хендлы задаются только в `index.html`** — восемь ссылок `https://t.me/streetvibetuning` и одна `https://instagram.com/streetvibetuning`. Telegram-хендл поставлен по аналогии с Instagram и **требует проверки**: если у ателье другой ник, замените его во всех ссылках разом.

Подписи каналов и кнопок переводятся ключами `chan.*` и `cta.*` в `i18n.js`.
